# 🌐 ReachOut - Rewati     
   
A modern, responsive personal portfolio/contact web application designed to connect people through a clean, minimal, and user-friendly interface. The project focuses on simplicity, responsiveness, and smooth user experience.     

---
     
## 🚀 Live Demo  
🔗 https://reachout-rewati.netlify.app/ 

---

## ✨ Features

- 📩 Clean and simple contact/landing interface  
- 📱 Fully responsive design (mobile, tablet, desktop)  
- ⚡ Fast loading and optimized UI  
- 🎨 Modern and minimal design layout  
- 🧭 Smooth navigation and user experience  
- 🌐 Deployed and accessible online via Netlify  
- 💡 Interactive and visually appealing interface  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox, Responsive Design)  
- JavaScript (Vanilla JS)  
- Netlify (Deployment)

## 🚀 How to Run Locally

1. Download or clone the repository  
2. Open the project folder  
3. Run `index.html` in any modern web browser  
4. No installation or server required
